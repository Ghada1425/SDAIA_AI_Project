# Mytool — تقييم المهارات العملية في الذكاء الاصطناعي

## فكرة المشروع

**Mytool** هو موقع تفاعلي قصير يقيس قدرة المستخدم العملية على استخدام الذكاء الاصطناعي، وليس مجرد معرفته النظرية بالأدوات. يقدّم التقييم مجموعة من المواقف اليومية التي تشبه قرارات العمل الحقيقية، ثم يحوّل الإجابات إلى ملف واضح قابل للفهم والمشاركة.

## المشكلة التي يحلها

ينتشر استخدام أدوات الذكاء الاصطناعي بسرعة، لكن من الصعب معرفة مستوى الشخص الحقيقي: هل يعرف كيف يكتب أمرًا جيدًا؟ هل يختار الأداة المناسبة؟ هل يتحقق من الإجابة؟ وهل يعرف ما الذي لا ينبغي مشاركته؟ غالبًا لا تعطي اختبارات المعرفة العامة إجابة عملية عن هذه الأسئلة، كما أن النتائج تكون إما سطحية أو غير قابلة للتنفيذ.

## الحل

يبني Mytool صورة مختصرة ومتوازنة عن أسلوب المستخدم في العمل مع الذكاء الاصطناعي من خلال:

- أسئلة مبنية على سيناريوهات عملية، وليست أسئلة حفظ للمصطلحات.
- نتيجة إجمالية من 100 مع تصنيف واضح للمستوى.
- تفصيل بصري للمهارات في ستة محاور.
- إظهار نقاط القوة ومجالات التطوير.
- توصيات شخصية مرتبطة بأضعف المحاور.
- تجربة عربية وإنجليزية كاملة مع دعم اتجاه RTL وLTR.
- نتيجة قابلة للطباعة أو الحفظ بصيغة PDF من نافذة المتصفح.

## المحاور التي يقيسها

1. **أساسيات الذكاء الاصطناعي:** فهم الذكاء الاصطناعي التوليدي، الهلوسة، واحتمالية اختلاف المخرجات.
2. **هندسة الأوامر:** كتابة أوامر واضحة، إضافة السياق، وتكوين قوالب قابلة لإعادة الاستخدام.
3. **اختيار الأداة:** مطابقة الأداة مع المهمة والخصوصية ومستوى الجودة المطلوب.
4. **الاستخدام العملي:** بناء سير عمل متكرر ومراجعة المخرجات قبل استخدامها.
5. **التفكير النقدي والتحقق:** فحص المصادر والافتراضات والأرقام والحالات الاستثنائية.
6. **الاستخدام المسؤول:** حماية البيانات الشخصية والسرية، والشفافية، والتحيز، والقرارات عالية المخاطر.

## المميزات

- هوية بصرية مستقلة باسم **Mytool** وشعار هندسي مبني على حرف M بشكل مجرد، يرمز إلى بناء طريقة عمل واضحة مع الذكاء الاصطناعي، دون استخدام رموز الروبوت أو الدماغ.
- واجهة هادئة ومتميزة بألوان فحمية وكريمية ولمسة ليمونية.
- شاشة افتتاحية توضح قيمة التقييم ومدته وخصوصيته.
- مؤشر تقدم واضح وتقسيم للمحاور أثناء الإجابة.
- اختيار واحد لكل سؤال مع حالات تفاعلية واضحة.
- نتيجة تحتوي على:
  - النتيجة الإجمالية ومؤشر Mytool.
  - المستوى: الأساس، المستكشف، الممارس، أو الاستراتيجي.
  - مخطط راداري لملف المهارات.
  - نقاط القوة ومجالات التطوير.
  - أشرطة تفصيل لكل محور.
  - توصيات شخصية للخطوة التالية.
- زر طباعة / حفظ PDF يعتمد على نافذة الطباعة الأصلية في المتصفح.
- لا يحتاج المستخدم إلى تسجيل حساب، ولا يتم إرسال الإجابات إلى خادم.
- تصميم متجاوب يعمل على الشاشات الكبيرة والأجهزة المحمولة.

## آلية التقييم

لكل سؤال أربعة خيارات، وتُعطى الإجابة درجة من 1 إلى 4 بحسب جودة الممارسة التي تعبّر عنها. توجد ثلاثة أسئلة في كل محور، ويُحسب متوسط المحور كنسبة مئوية. ثم تُجمع درجات المحاور للحصول على مؤشر Mytool من 100:

- **0–39 — الأساس:** بداية بناء العادات والمفاهيم.
- **40–59 — المستكشف:** قاعدة جيدة تحتاج إلى مزيد من التنظيم.
- **60–79 — الممارس:** استخدام مقصود مع فرصة لصقل التحقق واختيار الأداة.
- **80–100 — الاستراتيجي:** مزيج قوي من الحكم والمهارة والمسؤولية.

تعتمد نقاط القوة على أعلى محورين، وتُبنى التوصيات على أدنى محورين، لذلك تتغير صفحة النتائج من مستخدم إلى آخر.

## التقنيات المستخدمة

- HTML5 دلالي.
- CSS3 مخصص مع Grid وFlexbox وMedia Queries وPrint Styles.
- JavaScript ES Modules بدون إطار عمل أو اعتماد خارجي.
- SVG للهوية البصرية، والأيقونات، والمخطط الراداري.
- Google Fonts: Manrope وDM Mono وNoto Kufi Arabic.
- لا توجد قاعدة بيانات أو خدمة خلفية؛ التقييم محلي داخل المتصفح.

## طريقة التشغيل

### تشغيل سريع على Windows أو macOS أو Linux

يتطلب المشروع Node.js فقط، ولا يحتاج إلى تثبيت أي حزم:

```bash
cd SDAIA_AI_Project
npm start
```

ثم افتح:

```text
http://localhost:3000
```

يمكن أيضًا تشغيل `server.js` مباشرة:

```bash
node server.js
```

لإيقاف المعاينة اضغط `Ctrl + C`. ولإجراء فحص بناء JavaScript:

```bash
npm run check
```

## تنظيم الملفات

- `index.html` — نقطة الدخول والبيانات الوصفية.
- `styles.css` — الهوية والتخطيط والتجاوب والطباعة.
- `data.js` — الأسئلة والترجمات والمحاور والتوصيات، وهو الملف الأساسي للتحرير.
- `app.js` — منطق الشاشات والتفاعل والحسابات والنتائج.
- `logo.svg` — الشعار الأفقي.
- `favicon.svg` — الأيقونة المختصرة للمتصفح.

لإضافة سؤال، أضفه إلى مصفوفة `questions` في `data.js` مع `id` و`category` ونصين عربي وإنجليزي وأربعة خيارات. ولتعديل النصوص العامة، حدّث كائن `ui` في الملف نفسه.

## سبب اختيار الاسم والهوية

اختير اسم **Mytool** لأنه مباشر وسهل التذكر، ويعبّر عن فكرة امتلاك طريقة شخصية لاستخدام أدوات الذكاء الاصطناعي بوعي. صُمم الشعار على شكل حرف M هندسي مجرد، ليشير إلى بناء مسار عملي من الفكرة إلى النتيجة دون الاعتماد على رموز الروبوت أو الدماغ الشائعة. أما لوحة الألوان الفحميّة والليمونية فتعطي المنتج حضورًا مهنيًا مع لمسة تقنية هادئة.
